# Mobile Sync — แก้โค้ดใน Antigravity จากมือถือ

เปิดไฟล์ที่อยู่บนคอมจากเบราว์เซอร์มือถือ แล้วแก้แบบเรียลไทม์
- พิมพ์บนมือถือ ตัวอักษรขึ้นใน Antigravity บนคอมทันที และพิมพ์บนคอมก็ขึ้นบนมือถือทันที
- **ยังไม่เซฟก็คือยังไม่เซฟ** ทั้งสองฝั่งใช้ไฟล์เดียวกัน กด "บันทึก" บนมือถือเท่ากับกด Ctrl+S บนคอม
- **ไม่มีไฟล์โปรเจกต์อยู่บนมือถือ** มือถือแค่แสดงไฟล์ที่เปิดอยู่
- ถ้าพิมพ์พร้อมกันทั้งสองฝั่ง (เช่น AI ใน Antigravity กำลังแก้ไฟล์เดียวกัน) ระบบจะรวมการแก้ของทั้งสองฝั่งเข้าด้วยกัน ไม่ทิ้งของฝั่งไหน

## หน้าตาเหมือน IDE
- **แถบไอคอนด้านซ้าย** เหมือน Antigravity: Explorer, Search, Extensions, Problems, Settings
  - บนมือถือแนวตั้ง กด ☰ เพื่อเปิดแถบข้าง
  - บนแท็บเล็ตหรือจอแนวนอน แถบข้างจะค้างไว้ข้างตัวแก้โค้ดเหมือนบนคอม
- **Explorer** แสดงไฟล์เป็นต้นไม้โฟลเดอร์ แตะเพื่อพับหรือกาง มีส่วน Open Editors (ไฟล์ที่เปิดบนคอม) และปุ่มยุบโฟลเดอร์ทั้งหมด
- **Search** ค้นหาข้อความในทุกไฟล์ รวมถึงไฟล์ที่ยังไม่ได้บันทึก มีตัวเลือก Aa / ทั้งคำ / regex แตะผลลัพธ์เพื่อกระโดดไปที่บรรทัดนั้น มีโหมดค้นหาชื่อไฟล์ด้วย
- **Extensions** แสดงส่วนขยายที่ติดตั้งบนคอม แตะเพื่อดูคำสั่งของแต่ละตัวแล้วรันได้เลย
- **Problems** แสดง error/warning ทั้งโปรเจกต์ แตะเพื่อไปที่ตำแหน่งนั้น
- **แถบสถานะ** แสดงสถานะการเชื่อมต่อ, จำนวนปัญหา, บรรทัด/คอลัมน์ และภาษาของไฟล์

ข้อจำกัด: หน้าต่างพิเศษที่ส่วนขยายวาดเอง (เช่น Remote Explorer ของ SFTP หรือหน้าแชท AI) แสดงบนมือถือไม่ได้ เพราะ VS Code ไม่เปิดให้ส่วนขยายอื่นดึงหน้าจอพวกนั้นออกไปแสดงที่อื่น แต่**คำสั่ง**ของส่วนขยายเหล่านั้นยังรันได้จากแท็บ Extensions หรือปุ่ม ⚡

## หลายโปรเจกต์ / หลายหน้าต่าง
- **เปิด Antigravity กี่หน้าต่างก็ได้**
  - หน้าต่างแรกที่เปิด Mobile Sync จะเป็นตัวหลัก ถือพอร์ตและการเชื่อมต่อ VPS
  - หน้าต่างอื่นเข้ามาร่วมเอง (แถบล่างจะขึ้นว่า "(ร่วม)")
  - ถ้าปิดหน้าต่างหลัก หน้าต่างอื่นจะรับหน้าที่แทนภายในไม่กี่วินาที มือถือจะต่อใหม่เอง
- **สลับโปรเจกต์บนมือถือ:** แตะชื่อโปรเจกต์ที่หัว Explorer (หรือที่แถบสถานะ ⧉) จะเห็นทุกหน้าต่างที่เปิดอยู่บนคอม แตะเพื่อสลับ
- **เปิดโฟลเดอร์จากมือถือ:** ในหน้าโปรเจกต์ ไล่หาโฟลเดอร์ในคอมได้ หรือเลือกจาก "เปิดล่าสุด" แล้วเลือกว่าจะ
  - เปิดในหน้าต่างใหม่
  - เปิดแทนโปรเจกต์นี้ (หน้าต่างบนคอมจะโหลดใหม่ แล้วมือถือจะตามไปเอง)
  - เพิ่มเข้าหน้าต่างนี้ (หลายโฟลเดอร์ในหน้าต่างเดียว เหมือน Add Folder to Workspace)
- เมื่อกดเริ่ม Mobile Sync แล้ว มันจะเปิดเองในทุกหน้าต่างและทุกครั้งที่เปิด Antigravity จนกว่าจะกด "หยุด" ซึ่งจะหยุดทุกหน้าต่าง
- QR ที่สแกนจากหน้าต่างไหน มือถือจะเปิดโปรเจกต์ของหน้าต่างนั้น

## ใช้ extension ที่ติดตั้งบนคอมได้
มือถือแก้ไฟล์ตัวเดียวกับที่เปิดใน Antigravity extension บนคอมจึงทำงานตามปกติ
- **กด "บันทึก" บนมือถือ = กด Ctrl+S บนคอม** สิ่งที่ทำงานตอนเซฟจะทำงานครบ เช่น
  - SFTP ที่ตั้ง `"uploadOnSave": true` จะอัปโหลดให้เอง
  - format on save, ESLint fix on save ฯลฯ ถ้ามันแก้โค้ดตอนเซฟ การแก้นั้นจะเด้งมาที่มือถือด้วย
- **ปุ่ม ⚡ รันคำสั่ง:** ค้นหาและรันคำสั่งของ extension บนคอมได้ เช่น
  - "SFTP: Upload Active File" และ "SFTP: Download Active File"
  - "Format Document"
  คำสั่งจะทำงานกับไฟล์ที่เปิดอยู่บนมือถือ และคำสั่งที่ใช้ล่าสุดจะขึ้นไว้ด้านบน
  ถ้าคำสั่งไหนถามอะไรต่อ (เช่นให้เลือกจากรายการ) ต้องไปตอบบนคอม
  ถ้าไม่อยากให้มือถือรันคำสั่งได้ ให้ปิด `mobileSync.allowCommands`
- **error/warning จาก extension** (ESLint, Pylance, TypeScript, Lua ฯลฯ) ขึ้นเป็นเส้นใต้บนมือถือ
  แตะตัวนับ ✖ ⚠ ที่หัวจอเพื่อดูรายการ

## ความปลอดภัย (โค้ดไม่หลุด)
- **ไม่มีเซิร์ฟเวอร์กลาง** มือถือคุยกับคอมของคุณโดยตรงเท่านั้น ไม่มีการส่งโค้ดไปที่ไหน ไม่ต้องสมัครบัญชี
- ต้องมี **รหัสลับ** (สุ่มยาว 32 ตัวอักษร อยู่ใน QR) ถึงจะเข้าได้ ใส่รหัสผิด 10 ครั้งจะถูกบล็อก 15 นาที
- รหัสถูกเก็บใน keychain ของเครื่อง และไม่ถูกส่งไปกับลิงก์ (อยู่หลังเครื่องหมาย `#`)
- เปิดได้เฉพาะไฟล์ในโปรเจกต์ที่เปิดอยู่ หรือไฟล์ที่เปิดเป็นแท็บอยู่
- ทุกครั้งที่มีมือถือเชื่อมต่อ คอมจะเด้งแจ้งเตือนพร้อมที่อยู่ IP
- ถ้าสงสัยว่ารหัสหลุด สั่ง **Mobile Sync: Reset Secret Key** ลิงก์เก่าจะใช้ไม่ได้ทันที

⚠ ข้อมูลระหว่างมือถือกับคอมเป็น HTTP ธรรมดา (ไม่เข้ารหัส) ซึ่งใช้ใน **Wi-Fi บ้านของคุณเองได้**
แต่ **ห้ามใช้บน Wi-Fi สาธารณะ** (ร้านกาแฟ สนามบิน) ถ้าจะใช้นอกบ้าน ให้ใช้ **Tailscale** ซึ่งเข้ารหัสให้ทั้งหมด (ดูด้านล่าง)

## ติดตั้ง
1. ดาวน์โหลดไฟล์ `mobile-sync.vsix` จากโฟลเดอร์นี้
2. เปิด Antigravity แล้วกด `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
3. พิมพ์ **Extensions: Install from VSIX...** แล้วเลือกไฟล์ `mobile-sync.vsix`
4. ถ้ามันถามว่าเชื่อถือ extension นี้ไหม ให้กดยืนยัน

## ใช้งาน
1. เปิดโปรเจกต์ใน Antigravity
2. กด `Ctrl+Shift+P` แล้วพิมพ์ **Mobile Sync: Start**
   (หรือกดปุ่ม **Mobile Sync: off** ที่แถบล่างขวา)
3. ครั้งแรก Windows อาจเด้งถามเรื่อง Firewall ให้กด **Allow** สำหรับ **Private network** เท่านั้น
4. จะมีหน้า QR code ขึ้นมา สแกนด้วยกล้องมือถือ แล้วเปิดลิงก์
5. มือถือจะเปิดไฟล์ที่เปิดอยู่บนคอมให้เลย กด ☰ เพื่อเลือกไฟล์อื่นหรือค้นหาไฟล์

**บนมือถือ**
- จุดสีเขียว = เชื่อมต่ออยู่, เหลือง = กำลังเชื่อมต่อ, แดง = หลุด (จะต่อใหม่เองเมื่อคอมกลับมา)
- ● สีเหลืองข้างชื่อไฟล์ = ยังไม่ได้บันทึก
- แถบปุ่มด้านล่างมี Tab, ลูกศร, Undo/Redo และสัญลักษณ์ที่ใช้บ่อยในโค้ด `{ } ( ) [ ] ; = " '` ฯลฯ
- ☰ → ตั้งค่า: "เปิดไฟล์ตามคอมอัตโนมัติ" ถ้าเปิด เวลาสลับไฟล์บนคอม มือถือจะสลับตาม
- Android: เมนู Chrome → "เพิ่มลงในหน้าจอหลัก" จะได้ไอคอนเหมือนแอป

**หยุดใช้:** สั่ง **Mobile Sync: Stop** มือถือทุกเครื่องจะถูกตัดทันที

## ใช้นอกบ้านด้วย Tailscale (ฟรีสำหรับใช้ส่วนตัว)
1. ติดตั้ง Tailscale บนคอมและมือถือ แล้วล็อกอินบัญชีเดียวกันทั้งสองเครื่อง
2. สั่ง **Mobile Sync: Show QR Code / Link** จะมี QR ที่เขียนว่า "Tailscale (ใช้นอกบ้านได้)" เพิ่มขึ้นมา
3. สแกน QR อันนั้น ใช้ได้ทุกที่ที่มีเน็ต และข้อมูลถูกเข้ารหัส
4. (ไม่บังคับ) ถ้าอยากให้เข้าได้ **เฉพาะ** ผ่าน Tailscale: Settings → ค้นหา `mobileSync.host` → ใส่ IP Tailscale ของคอม (ขึ้นต้นด้วย `100.`)

## ใช้นอกบ้านผ่าน VPS ของคุณเอง
มือถือเปิดลิงก์ `https://` ของ VPS ได้จากทุกที่ ไม่ต้องลงแอปเพิ่มบนมือถือ
คอมจะเป็นฝ่าย**ต่อออกไปหา VPS เอง** จึงไม่ต้องเปิดพอร์ตที่เราเตอร์บ้าน

```
มือถือ ──HTTPS──▶ VPS (mobile-sync-relay) ◀──WSS── Antigravity บนคอม
```

ไฟล์ที่ใช้อยู่ใน `relay/bin/`:
- `mobile-sync-relay.exe` สำหรับ Windows Server 2012, 2012 R2 และรุ่นใหม่กว่า
- `mobile-sync-relay-linux` สำหรับ VPS ที่เป็น Linux

### 1. ทำชื่อโดเมนฟรี (แนะนำมาก)
ถ้ามีโดเมน มือถือจะได้ HTTPS แท้ (Let's Encrypt) ไม่ขึ้นคำเตือน
1. เข้า duckdns.org แล้วล็อกอิน
2. ตั้งชื่อ เช่น `mycode` แล้วใส่ IP ของ VPS ในช่อง current ip และกด update ip
3. จะได้โดเมน `mycode.duckdns.org`

ถ้ามีโดเมนของตัวเองอยู่แล้ว ให้ตั้ง A record ชี้ไปที่ IP ของ VPS แทนก็ได้

ถ้าไม่มีโดเมน ใช้ IP ตรงๆ ก็ได้ แต่มือถือจะขึ้นคำเตือนใบรับรองทุกครั้ง และต้องกด "ดำเนินการต่อ"

### 2. ติดตั้งบน VPS แบบง่าย (ตัวติดตั้ง)
ใช้ไฟล์ `relay/bin/mobile-sync-relay-windows.zip`
1. แตก zip ไว้ที่ไหนก็ได้ใน VPS
2. คลิกขวาที่ `install-relay.cmd` → **Run as administrator**
3. พิมพ์**ชื่อโดเมนสำหรับ relay** เช่น `code.newgtx.net`
   - แนะนำให้ใช้**โดเมนย่อย** โดยเพิ่ม A record `code` ชี้มาที่ IP ของ VPS ก่อน
   - ถ้าพิมพ์โดเมนที่มีเว็บใน IIS ใช้อยู่แล้ว (เช่น `newgtx.net`) ตัวติดตั้งจะแจ้งว่า**โดเมนซ้ำ** และให้พิมพ์โดเมนย่อยแทน
   - ถ้าโดเมนยังไม่ได้ชี้มาที่ VPS จะมีคำเตือน
4. ถ้า IIS ใช้พอร์ต 80/443 อยู่ ตัวติดตั้งจะทำให้เอง:
   - สร้างโฟลเดอร์ `C:\mobile-sync\www`
   - สร้าง**เว็บใหม่ใน IIS** ชื่อ `MobileSync-code.newgtx.net` ชี้มาที่โฟลเดอร์นั้น เว็บเดิมของคุณไม่ถูกแตะ
     เว็บนี้ใช้แค่ตอนขอและต่ออายุใบรับรอง HTTPS เท่านั้น
   - ถ้าพอร์ต 80 ถูกโปรแกรมอื่นที่ไม่ใช่ IIS จับไว้ จะแจ้งให้รู้
   - ถ้าพอร์ต 8443 ไม่ว่าง จะเลื่อนไปใช้พอร์ตถัดไปและแจ้งให้รู้

   จากนั้นมันจะทำต่อให้เองทั้งหมด:
   - ขอใบรับรอง HTTPS
   - เปิดไฟร์วอลล์
   - ตั้งให้รันเองทุกครั้งที่ VPS เปิดเครื่อง
   - คัดลอกข้อความเชื่อมต่อไว้ใน clipboard ให้
5. ถ้าผู้ให้บริการ VPS มีไฟร์วอลล์ในหน้าเว็บ ให้เปิดพอร์ตที่ตัวติดตั้งแจ้งไว้ที่นั่นด้วย
6. ไปที่ข้อ 3 (ตั้งค่าบนคอม) ได้เลย

ถอนการติดตั้ง: คลิกขวาที่ `uninstall-relay.cmd` → Run as administrator (จะลบเว็บ `MobileSync-...` ที่มันสร้างใน IIS ออกด้วย)

ถ้าอยากทำเองทีละขั้น ดูข้อ 2A หรือ 2B ด้านล่าง

### 2A. VPS ที่มี IIS ใช้พอร์ต 80/443 อยู่แล้ว
relay จะรัน HTTPS ที่พอร์ต **8443** โดยไม่ไปยุ่งกับเว็บที่อยู่ใน IIS
ตอนขอใบรับรอง Let's Encrypt มันจะวางไฟล์ยืนยันชั่วคราวในโฟลเดอร์เว็บของ IIS แล้วลบทิ้งเมื่อเสร็จ (วิธีเดียวกับโปรแกรม win-acme)
ใบรับรองจะต่ออายุเองทุกประมาณ 60 วัน

1. **ทำโดเมนย่อย:** ที่ผู้ให้บริการ DNS ของโดเมนคุณ เพิ่ม **A record** ชื่อ `code` ชี้ไปที่ IP ของ VPS
   จะได้ `code.โดเมนคุณ.com` แยกจากเว็บเดิม ไม่กระทบกัน
2. **ให้ IIS รับชื่อนี้ที่พอร์ต 80:** เปิด IIS Manager แล้วดูเว็บที่ใช้พอร์ต 80
   - ถ้า **Default Web Site** มี binding `http` พอร์ต 80 ที่ไม่ได้ใส่ Host name ไว้ แปลว่ารับทุกชื่ออยู่แล้ว ไม่ต้องทำอะไร
   - ถ้าไม่ใช่ ให้คลิกขวาที่เว็บที่จะใช้ → **Edit Bindings…** → **Add** → Type `http`, Port `80`, Host name `code.โดเมนคุณ.com`
   - จดโฟลเดอร์ของเว็บนั้นไว้ (คลิกขวา → Manage Website → Advanced Settings → **Physical Path**) ส่วนใหญ่คือ `C:\inetpub\wwwroot`
3. **เปิดพอร์ต 8443:** เปิด **Command Prompt แบบ Administrator**
   ```
   netsh advfirewall firewall add rule name="Mobile Sync Relay" dir=in action=allow protocol=TCP localport=8443
   ```
   ถ้าผู้ให้บริการ VPS มีไฟร์วอลล์ในหน้าเว็บ ให้เปิดพอร์ต 8443 ที่นั่นด้วย (พอร์ต 80 ของ IIS เปิดอยู่แล้ว)
4. คัดลอก `mobile-sync-relay.exe` ไปไว้ที่ `C:\mobile-sync\` แล้ว**ดับเบิลคลิก**
   - คำถามแรก พิมพ์ `code.โดเมนคุณ.com` แล้วกด Enter
   - คำถามที่สอง (เรื่อง IIS) พิมพ์โฟลเดอร์จากข้อ 2 เช่น `C:\inetpub\wwwroot` แล้วกด Enter
5. relay จะทดสอบเองก่อนว่า IIS ส่งไฟล์ยืนยันได้ แล้วจึงขอใบรับรอง
   ถ้าไม่ผ่าน มันจะบอกว่าติดตรงไหน (DNS ยังไม่ชี้มา หรือ IIS ยังไม่รับชื่อนี้)
   แก้แล้ว**ดับเบิลคลิกใหม่ได้เลย** ไม่ต้องตอบคำถามซ้ำ
6. ถ้าผ่าน จะมีข้อความ `https://code.โดเมนคุณ.com:8443#key=...` ขึ้นมา และถูกบันทึกไว้ในไฟล์ `connect-string.txt` ด้วย
   **ข้อความนี้คือรหัสลับ ห้ามให้ใคร**
7. ให้รันเองทุกครั้งที่ VPS รีสตาร์ต (ทำหลังจากข้อ 6 สำเร็จแล้วเท่านั้น):
   ```
   schtasks /create /tn "MobileSyncRelay" /tr "C:\mobile-sync\mobile-sync-relay.exe" /sc onstart /ru SYSTEM /f
   ```
   แล้วปิดหน้าต่างดำที่เปิดไว้ และสั่ง `schtasks /run /tn "MobileSyncRelay"`

### 2B. VPS ที่พอร์ต 80/443 ว่าง
1. เปิด **Command Prompt แบบ Administrator** แล้วเปิดไฟร์วอลล์:
   ```
   netsh advfirewall firewall add rule name="Mobile Sync Relay" dir=in action=allow protocol=TCP localport=80,443
   ```
   ถ้าผู้ให้บริการ VPS มีไฟร์วอลล์ในหน้าเว็บด้วย ให้เปิดพอร์ต 80 และ 443 ที่นั่นด้วย
2. คัดลอก `mobile-sync-relay.exe` ไปไว้ที่ `C:\mobile-sync\` แล้วดับเบิลคลิก
   - พิมพ์โดเมน (หรือ IP ของ VPS)
   - คำถามเรื่อง IIS ให้กด Enter ข้ามไป
3. คัดลอกข้อความ `https://...#key=...` ที่ขึ้นมา (อยู่ใน `connect-string.txt` ด้วย) แล้วตั้งให้รันเองด้วยคำสั่ง `schtasks` เหมือนข้อ 2A.7

ถ้าเป็น Linux: รัน `./mobile-sync-relay-linux` ด้วยสิทธิ์ root หรือเปิดสิทธิ์ใช้พอร์ต 443 ให้มัน

### 3. ตั้งค่าบนคอม
1. ใน Antigravity กด `Ctrl+Shift+P` → **Mobile Sync: Connect to VPS Relay**
2. วางข้อความ `https://...#key=...` ที่ได้จากข้อ 2 (ตัวติดตั้งคัดลอกไว้ให้แล้ว)
3. สั่ง **Mobile Sync: Start** แถบล่างจะขึ้น `VPS ✓` เมื่อต่อติด
4. สแกน QR ที่เขียนว่า **"ผ่าน VPS (ใช้ได้ทุกที่)"** ถ้ารันที่พอร์ต 8443 ลิงก์จะเป็น `https://code.โดเมนคุณ.com:8443/...`

**แนะนำ:** ถ้าใช้ผ่าน VPS อย่างเดียว ให้ไปที่ Settings → `mobileSync.host` แล้วใส่ `127.0.0.1`
คอมจะไม่เปิดรับการเชื่อมต่อจาก Wi-Fi เลย ทุกอย่างต้องผ่าน VPS

### ความปลอดภัยของโหมด VPS
- ระหว่างมือถือกับ VPS เข้ารหัสด้วย HTTPS และระหว่าง VPS กับคอมเข้ารหัสด้วย WSS
- key ของคอมไม่ถูกส่งผ่านเน็ตเลย คอมยืนยันตัวด้วยการตอบคำถามที่คำนวณจาก key (HMAC)
- ในโหมด IP คอมจะตรวจลายนิ้วมือใบรับรองของ VPS ก่อนเสมอ ถ้าไม่ตรงจะไม่ยอมต่อ
- รหัสในลิงก์ของมือถือยังถูกตรวจที่**คอม** แม้มีคนเข้าถึง VPS ได้ก็ใช้รหัสนั้นแทนไม่ได้
- ⚠ แต่ **VPS เห็นโค้ดที่วิ่งผ่าน** เพราะเป็นจุดที่ถอดรหัส HTTPS ถ้า VPS ถูกเจาะ คนเจาะจะอ่านโค้ดได้
- ⚠ **Windows Server 2012 / 2012 R2 หมดระยะการอัปเดตความปลอดภัยแล้ว** (ตั้งแต่ ต.ค. 2023) ควรตั้งรหัสผ่าน RDP ให้แข็งแรง และไม่ลงโปรแกรมอื่นที่ไม่จำเป็น
  ถ้าย้ายไปใช้ Windows Server รุ่นใหม่หรือ Linux ได้จะปลอดภัยกว่า
- ถ้าสงสัยว่า key หลุด: บน VPS ลบไฟล์ `relay-config.json` แล้วรันใหม่ จะได้ key ใหม่ จากนั้นสั่ง Connect to VPS Relay บนคอมอีกครั้ง

## ตั้งค่า (Settings → ค้นหา "Mobile Sync")
| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `mobileSync.port` | `8765` | พอร์ตที่มือถือเชื่อมต่อ |
| `mobileSync.host` | `0.0.0.0` | ฟังทุกเครือข่าย, `127.0.0.1` = ผ่าน VPS อย่างเดียว, หรือใส่ IP Tailscale ถ้าอยากใช้ผ่าน Tailscale อย่างเดียว |
| `mobileSync.autoStart` | ปิด | เปิดเองทุกครั้งที่เปิด Antigravity |
| `mobileSync.notifyOnConnect` | เปิด | แจ้งเตือนเมื่อมีมือถือเชื่อมต่อ |
| `mobileSync.allowCommands` | เปิด | ให้มือถือรันคำสั่งของ extension บนคอมได้ (ปุ่ม ⚡) |

## ข้อจำกัด
- ต้องเปิดคอมและ Antigravity ไว้ ห้ามให้คอม sleep
- ใช้แก้ไฟล์ข้อความ/โค้ดเท่านั้น ไฟล์ใหญ่เกิน 5 MB เปิดไม่ได้
- ยังไม่มี terminal และยังไม่ได้แสดงเคอร์เซอร์ของอีกฝั่ง
- ทดสอบอัตโนมัติกับตัวจำลองของ VS Code, เบราว์เซอร์ขนาดมือถือ, ตัว relay (โหมด IP บน Linux) และการขอใบรับรองผ่านโฟลเดอร์ IIS กับ Pebble (เซิร์ฟเวอร์ทดสอบของ Let's Encrypt) แล้ว แต่ยังไม่ได้ทดสอบกับ Antigravity ตัวจริง, IIS จริงบน Windows Server 2012 R2 หรือ Let's Encrypt ตัวจริง ถ้าเจอปัญหาแจ้งได้เลย

## สำหรับนักพัฒนา
```
npm install
npm test          # build + ทดสอบ sync และโหมด VPS แบบ end-to-end ด้วย Playwright
npm run relay     # build relay (Go 1.20 เพื่อให้รันบน Windows Server 2012 ได้)
npm run package   # สร้าง mobile-sync.vsix
```
- `src/extension.js` — คำสั่ง, status bar, หน้า QR
- `src/server.js` — HTTP + Server-Sent Events, ตรวจรหัส, รวมการแก้ที่ชนกัน (rebase ด้วย ChangeSet ของ CodeMirror)
- `src/relay.js` — ฝั่งคอมที่ต่อออกไปหา VPS แล้วส่งต่อคำขอจากมือถือ
- `relay/main.go` — ตัว relay บน VPS (HTTPS + Let's Encrypt อัตโนมัติ)
- `web/main.js` — หน้าเว็บบนมือถือ (CodeMirror 6) → build เป็น `media/app.js`
