# Mobile Sync — แก้โค้ดใน Antigravity จากมือถือ

เปิดไฟล์ที่อยู่บนคอมจากเบราว์เซอร์มือถือ แล้วแก้แบบเรียลไทม์
- พิมพ์บนมือถือ ตัวอักษรขึ้นใน Antigravity บนคอมทันที และพิมพ์บนคอมก็ขึ้นบนมือถือทันที
- **ยังไม่เซฟก็คือยังไม่เซฟ** ทั้งสองฝั่งใช้ไฟล์เดียวกัน กด "บันทึก" บนมือถือเท่ากับกด Ctrl+S บนคอม
- **ไม่มีไฟล์โปรเจกต์อยู่บนมือถือ** มือถือแค่แสดงไฟล์ที่เปิดอยู่
- ถ้าพิมพ์พร้อมกันทั้งสองฝั่ง (เช่น AI ใน Antigravity กำลังแก้ไฟล์เดียวกัน) ระบบจะรวมการแก้ของทั้งสองฝั่งเข้าด้วยกัน ไม่ทิ้งของฝั่งไหน

## ความปลอดภัย (โค้ดไม่หลุด)
- **ไม่มีเซิร์ฟเวอร์กลาง** มือถือคุยกับคอมของคุณโดยตรงเท่านั้น ไม่มีการส่งโค้ดไปที่ไหน ไม่ต้องสมัครบัญชี
- ต้องมี **รหัสลับ** (สุ่มยาว 32 ตัวอักษร อยู่ใน QR) ถึงจะเข้าได้ ใส่รหัสผิด 10 ครั้งจะถูกบล็อก 15 นาที
- รหัสถูกเก็บใน keychain ของเครื่อง และไม่ถูกส่งไปกับลิงก์ (อยู่หลังเครื่องหมาย `#`)
- เปิดได้เฉพาะไฟล์ในโปรเจกต์ที่เปิดอยู่ หรือไฟล์ที่เปิดเป็นแท็บอยู่
- ทุกครั้งที่มีมือถือเชื่อมต่อ คอมจะเด้งแจ้งเตือนพร้อมที่อยู่ IP
- ถ้าสงสัยว่ารหัสหลุด สั่ง **Mobile Sync: Reset Secret Key** ลิงก์เก่าจะใช้ไม่ได้ทันที

⚠ ข้อมูลระหว่างมือถือกับคอมเป็น HTTP ธรรมดา (ไม่เข้ารหัส) ซึ่งใช้ใน **Wi-Fi บ้านของคุณเองได้**
แต่ **ห้ามใช้บน Wi-Fi สาธารณะ** (ร้านกาแฟ สนามบิน) ถ้าจะใช้นอกบ้าน ให้ใช้ **Tailscale** ซึ่งเข้ารหัสให้ทั้งหมด (ดูด้านล่าง)

## ติดตั้ง
1. ดาวน์โหลดไฟล์ `mobile-sync.vsix` จากโฟลเดอร์นี้
2. เปิด Antigravity แล้วกด `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`)
3. พิมพ์ **Extensions: Install from VSIX...** แล้วเลือกไฟล์ `mobile-sync.vsix`
4. ถ้ามันถามว่าเชื่อถือ extension นี้ไหม ให้กดยืนยัน

## ใช้งาน
1. เปิดโปรเจกต์ใน Antigravity
2. กด `Ctrl+Shift+P` แล้วพิมพ์ **Mobile Sync: Start**
   (หรือกดปุ่ม **Mobile Sync: off** ที่แถบล่างขวา)
3. ครั้งแรก Windows อาจเด้งถามเรื่อง Firewall ให้กด **Allow** สำหรับ **Private network** เท่านั้น
4. จะมีหน้า QR code ขึ้นมา สแกนด้วยกล้องมือถือ แล้วเปิดลิงก์
5. มือถือจะเปิดไฟล์ที่เปิดอยู่บนคอมให้เลย กด ☰ เพื่อเลือกไฟล์อื่นหรือค้นหาไฟล์

**บนมือถือ**
- จุดสีเขียว = เชื่อมต่ออยู่, เหลือง = กำลังเชื่อมต่อ, แดง = หลุด (จะต่อใหม่เองเมื่อคอมกลับมา)
- ● สีเหลืองข้างชื่อไฟล์ = ยังไม่ได้บันทึก
- แถบปุ่มด้านล่างมี Tab, ลูกศร, Undo/Redo และสัญลักษณ์ที่ใช้บ่อยในโค้ด `{ } ( ) [ ] ; = " '` ฯลฯ
- ☰ → ตั้งค่า: "เปิดไฟล์ตามคอมอัตโนมัติ" ถ้าเปิด เวลาสลับไฟล์บนคอม มือถือจะสลับตาม
- Android: เมนู Chrome → "เพิ่มลงในหน้าจอหลัก" จะได้ไอคอนเหมือนแอป

**หยุดใช้:** สั่ง **Mobile Sync: Stop** มือถือทุกเครื่องจะถูกตัดทันที

## ใช้นอกบ้านด้วย Tailscale (ฟรีสำหรับใช้ส่วนตัว)
1. ติดตั้ง Tailscale บนคอมและมือถือ แล้วล็อกอินบัญชีเดียวกันทั้งสองเครื่อง
2. สั่ง **Mobile Sync: Show QR Code / Link** จะมี QR ที่เขียนว่า "Tailscale (ใช้นอกบ้านได้)" เพิ่มขึ้นมา
3. สแกน QR อันนั้น ใช้ได้ทุกที่ที่มีเน็ต และข้อมูลถูกเข้ารหัส
4. (ไม่บังคับ) ถ้าอยากให้เข้าได้ **เฉพาะ** ผ่าน Tailscale: Settings → ค้นหา `mobileSync.host` → ใส่ IP Tailscale ของคอม (ขึ้นต้นด้วย `100.`)

## ตั้งค่า (Settings → ค้นหา "Mobile Sync")
| ค่า | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `mobileSync.port` | `8765` | พอร์ตที่มือถือเชื่อมต่อ |
| `mobileSync.host` | `0.0.0.0` | ฟังทุกเครือข่าย ใส่ IP Tailscale ถ้าอยากจำกัดให้ใช้ผ่าน Tailscale อย่างเดียว |
| `mobileSync.autoStart` | ปิด | เปิดเองทุกครั้งที่เปิด Antigravity |
| `mobileSync.notifyOnConnect` | เปิด | แจ้งเตือนเมื่อมีมือถือเชื่อมต่อ |

## ข้อจำกัด
- ต้องเปิดคอมและ Antigravity ไว้ ห้ามให้คอม sleep
- ใช้แก้ไฟล์ข้อความ/โค้ดเท่านั้น ไฟล์ใหญ่เกิน 5 MB เปิดไม่ได้
- ยังไม่มี terminal และยังไม่ได้แสดงเคอร์เซอร์ของอีกฝั่ง
- ทดสอบอัตโนมัติกับตัวจำลองของ VS Code และเบราว์เซอร์ขนาด iPhone แล้ว แต่ยังไม่ได้ทดสอบกับ Antigravity ตัวจริง ถ้าเจอปัญหาแจ้งได้เลย

## สำหรับนักพัฒนา
```
npm install
npm test          # build + ทดสอบ sync แบบ end-to-end ด้วย Playwright
npm run package   # สร้าง mobile-sync.vsix
```
- `src/extension.js` — คำสั่ง, status bar, หน้า QR
- `src/server.js` — HTTP + Server-Sent Events, ตรวจรหัส, รวมการแก้ที่ชนกัน (rebase ด้วย ChangeSet ของ CodeMirror)
- `web/main.js` — หน้าเว็บบนมือถือ (CodeMirror 6) → build เป็น `media/app.js`
